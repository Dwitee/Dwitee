## About Me

With nearly two decades of engineering experience across **Big Tech, gaming, enterprise platforms, and AI-first startups**, I design and ship scalable backend systems, secure cloud-native architectures, and production-grade AI solutions — spanning backend system design, microservices (Python/FastAPI, Java/Spring Boot), API engineering, distributed systems, and agentic/multimodal AI applications.

From architecting **India's first large-scale e-commerce gamezone platform at Flipkart**, to building game platforms at **MechMocha** and shipping gameplay code at **EA Games**, to advancing AI accessibility research at **King's College London** — I blend enterprise-grade engineering discipline with rapid innovation.

**Currently @ [Areeva.ai](https://areeva.ai)** — building AI/ML-driven conversational platforms that enable autonomous AI agents to run real-time voice/video interactions, deployed at scale on AWS (EKS, ECR, Karpenter) with a focus on productionising LLM systems through CI/CD, monitoring, and model evaluation.
